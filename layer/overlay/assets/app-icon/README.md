# Illostrator app icon

A **purple rocker cat**: sunglasses, a yellow crown of a mohawk and a leather jacket, playing a pink
guitar whose body is drawn as a vector path, anchors and Bezier handles showing, with a
fountain-pen nib for a pick. A yellow lightning bolt behind, on a cream (`#fff4e4`) to peach
(`#ffd8c4`) gradient, the same field as Loloshop's giraffe.

A 512-unit tile (`viewBox="0 0 512 512"`), rounded square with `rx=112`. The file names keep
VectorCraft's (`vectorcraft.*`, `ai.storyteller.vectorcraft.png`) so the build scripts and packaging
find them unchanged; the 128 px hicolor PNG is also the mark in the app bar and the About box.
Regenerate the PNG, ICO and hicolor renders with `packaging/icons.sh`.
